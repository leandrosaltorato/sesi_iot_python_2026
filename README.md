# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias
- Python
- VsCode ou PyCharm

## Arquivos
- `soma.py`, `condicional.py`, `for.py`: exemplos da aula
- `exercicio01_media.py`: média de três números
- `exercicio02_temperatura.py`: conversor de Celsius para Fahrenheit
- `exercicio03_par_impar.py`: número par ou ímpar
- `exercicio04_fatorial.py`: cálculo de fatorial
- `exercicio05_bissexto.py`: verificador de ano bissexto
- `exercicio06_positivo_negativo.py`: número positivo, negativo ou zero
- `exercicio07_comparacao.py`: maior de dois números
- `exercicio08_idade.py`: maior ou menor de idade
- `exercicio09_triangulo.py`: classificação de triângulos

## Para testar
```bash
python nome_arquivo.py
```
